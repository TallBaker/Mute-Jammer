# Mute-Jammer
My attempt at making a life-sized working mute jammer.

A massive thanks to jbalagiya (https://github.com/jbalagiya) for the actual jamming code, wouldn't have been possible without them. 

This bluetooth jammer uses an nrf24l01 with a Power Amplifier (PA) and Low Noise Amplifier (LNA). It uses a small 0.96 inch oled screen to display the mute badge / icon when the jammer is working.

The actual build itself is split up into multiple parts for easier 3D printing. The legs are split into 3, the body into 2, and the handles into 3 as well. These should be able to be assembled with bolts.
